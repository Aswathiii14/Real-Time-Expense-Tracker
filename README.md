
# 💰 Expense Tracker GUI using Python (Tkinter)

A simple and user-friendly desktop application to track daily expenses using **Python** and **Tkinter GUI**.  
It allows users to add, view, and analyze expenses stored in a CSV file.

---

## 🚀 Features
- ➕ Add new expenses (date, category, description, amount, payment method, notes)
- 📄 View all expenses in a table
- 🧹 Clear all expenses with one click
- 📊 View total by category
- 💵 Calculate total expense
- 💾 Automatically stores data in a CSV file
- 🎨 Clean and easy-to-use interface

---

## 🧩 Tech Stack
- **Language:** Python
- **GUI Library:** Tkinter
- **Data Storage:** CSV
- **Modules Used:** `csv`, `datetime`, `os`, `tkinter`, `ttk`, `collections`
